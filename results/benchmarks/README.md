# Benchmarks

This directory contains benchmark experiment outputs. The current benchmark
collection is the Information Processing Capacity (IPC) study:

- [`ipc/`](ipc/README.md) — experiment folders, job definitions, metrics, and
  plot instructions for the IPC benchmarks.

Run logs are generated under their corresponding experiment folders and are
excluded from Git; observable logs are grouped by Hamiltonian. Experiment
documentation and job definitions are tracked.
