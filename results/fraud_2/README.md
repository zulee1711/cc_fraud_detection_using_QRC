# fraud_2 — report section 7.2: QRC vs classical baselines against window length

**Question.** On fraud detection with raw transaction windows, does the sliding-window QRC beat classical
models on the same window as the window gets longer, and does the edge survive shot noise?

**Setup.** Data `data/sc3_c1000_x6` (recipe in its README), feature set 1 (raw log amount), window lengths
L = 1, 3, 5, 10, 15, 20, 30, reservoir seeds 42–51. QRC: 1 input + 3 memory qubits, input reset, three reservoirs
at their CLI defaults (random circuit depth 4, TFIM, native exchange), each read out with Z+ZZ (7 observables) and
XYZ-strings (45), exact and at 10⁵ / 10⁴ shots per window. Baselines: logistic regression on the raw window,
untuned ESNs of each readout width (7 and 45 units), LSTM. Details in the docstring of
[`experiments/fraud_2/run.py`](../../experiments/fraud_2/run.py).

## Reproduce

From the repository root:

```bash
.venv/bin/python -m experiments.fraud_2.run check          # readout variants == NumpyBackend
experiments/fraud_2/run_jobs.sh                             # the 427 jobs of experiments/fraud_2/jobs.txt
.venv/bin/python results/fraud_2/aggregate.py               # runs.csv, tables.md, fraud_ap_vs_L, fraud_shots
.venv/bin/python results/fraud_2/seed_spread.py             # seed_spread.md and seed_spread_*.png
```

The stored runs were produced on GitHub Actions (Linux). A local rerun gives the same metrics up to platform
floating-point differences, at most ~2·10⁻³ in test customer AP for the 45-feature exact readouts.

## Findings (test customer AP, mean over 10 seeds; `tables.md`)

- **Z+ZZ readout:** every QRC is below the logistic baseline from L = 5 on (L = 15: TFIM 0.185, logistic 0.406).
- **XYZ-strings readout, exact:** TFIM is above logistic from L = 3 to 20 (L = 10: 0.351 vs 0.331; L = 15: 0.429
  vs 0.406; L = 20: 0.481 vs 0.465), and below it at L = 30 (0.538 vs 0.558). It is above the equal-width ESN-45
  from L = 15 (0.429 vs 0.398); the ESN is ahead up to L = 5 and level at L = 10 (0.358).
- **Shot noise:** at 10⁵ shots per window TFIM falls below logistic at every L (L = 15: 0.359); 10⁴ shots is lower
  still.
- **LSTM** is far ahead at every L > 1 (L = 15: 0.771).
